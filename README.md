# Lumi Cinema — Монгол орчуулгатай кино худалдаалах сайт

GitHub-д оруулахад бэлэн Node.js 24 + SQLite төсөл. Гаднын npm сан шаардлагагүй.

## Ажиллуулах — Codespaces / компьютер

ZIP-ээ задлаад доторх файлуудыг GitHub repository-ийн үндсэн хэсэгт оруулна. GitHub дээр **Code → Codespaces → Create codespace**.

Төслийн хавтас дахь терминалд:

```bash
cp .env.example .env
npm run admin
npm start
```

`npm run admin` нь таны сонгосон нэр, 12-оос дээш тэмдэгттэй нууц үгээр админ үүсгэнэ. Анхдагч эсвэл нийтэд ил нууц үг байхгүй. Терминалд бичих нууц үг харагдана; дэлгэцээ хуваалцаж байхдаа бүү оруулаарай.

Ports хэсгээс **8080 → Open in Browser**. Codespaces хаягаар ажиллуулахдаа `.env` дэх `PUBLIC_ORIGIN`-ийг нээгдсэн **https://…app.github.dev** хаягаар (сүүлийн `/`-гүй) солиод `COOKIE_SECURE=true` болгоно. Ctrl+C дарж зогсоогоод `npm start`-аар дахин асаана. PUBLIC_ORIGIN нь браузерын хаягтай яг таарах ёстой.

Локал компьютер дээр Node.js 24 шаардлагатай. `http://localhost:8080`-оор нээхэд анхны `.env` тохиргоо хангалттай.

## Анх тохируулах дараалал

1. Үүсгэсэн админ нэр, нууц үгээр сайтдаа нэвтэрнэ.
2. Баруун дээд талын нэр → **Админ самбар**.
3. **Тохиргоо** хэсэгт сайтын нэр, банк, данс/IBAN, данс эзэмшигч, холбоо барих мэдээллээ хадгална.
4. **Кино нэмэх** → нэр, төрөл, үнэ, он, үргэлжлэх хугацаа, тайлбар оруулна.
5. Босоо постер болон MP4/WebM видеогоо сонгоно. MP4 H.264 + AAC нь утсанд илүү нийцтэй. Систем автоматаар кодек хөрвүүлэхгүй.
6. **Нийтлэх**-ийг сонгоод **Кино хадгалах**. Файлыг оруулж дуустал хуудсаа хаахгүй.
7. **Нүүрэнд онцлох**-оор нүүрний том хэсэгт гаргана.

Кино оруулаагүй үед нүүрэнд худалдаалах боломжгүй, тодорхой тэмдэглэсэн дизайны жишээ картууд гарна. Эдгээр нь бодит кино биш; анхны кино нийтэлмэгц арилна.

## Төлбөр шалгах

Хэрэглэгч кино сонгон дансны мэдээллийг харж, үнийг шилжүүлнэ. Гүйлгээний утгад давхцахгүй 6 оронтой хэрэглэгчийн ID-гаа бичнэ. Дараа нь шилжүүлсэн нэр/цагаа бичиж хүсэлт илгээнэ.

Админ **Төлбөр шалгах** хэсгээс хүсэлтийг харна. **Өөрийн банкны хуулгаас төлбөр орсныг шалгасны дараа** батална. Баталмагц зөвхөн тухайн хэрэглэгчид тухайн киноны эрх нээгдэнэ. Татгалзвал шалтгаан хэрэглэгчид харагдана. Дахин хүсэлт гаргаж болно. Баталгаажсан эрх хугацаагүй; кино нийтлэгдсэн хэвээр байгаа үед үзнэ.

Үнэ нь сервер дээр тухайн хүсэлт гарсан үеийн үнээр хадгалагдана. Хэрэглэгч хүсэлтийн дүн эсвэл өөрийн эрхийг өөрчилж чадахгүй. Энэ хувилбар банкны автомат холболтгүй.

## Бэлэн боломжууд

- Монгол интерфейс, утас/таблет/компьютерт тохирсон загвар
- Нүүр, онцлох кино, шинэ кино, кино сан, төрөл, хайлт
- 5-аас олон кинотой бол их үзэлттэй хэсэг
- Нэвтрэх нэр + нууц үгээр бүртгэл, хувийн 6 оронтой ID
- Кино бүрийн үнэ, үнэ төлбөргүй кино, миний кино, төлбөрийн түүх
- Админ: кино нэмэх/засах, ноорог/нийтлэх, постер/видео оруулах
- Админ: хүсэлт батлах/татгалзах, борлуулалтын дүн, ID/нэрээр хэрэглэгч хайх
- Сервер талд эрх шалгах, хамгаалалттай MP4/WebM, byte-range тоглуулах
- PWA manifest, утасны нүүр дэлгэцэд нэмэх icon
- SQLite өгөгдөл, нууц үгийн scrypt hash, HttpOnly session, same-origin хүсэлтийн шалгалт
- Нэг хүсэлтийг давхар батлах болон хүлээгдэж буй хүсэлтийг давхар үүсгэхээс хамгаалсан

## GitHub ба нийтэд ажиллуулах

**GitHub нь кодыг хадгална. GitHub Pages дангаараа энэ сервертэй сайтыг ажиллуулахгүй.** Codespaces нь хөгжүүлэх/турших орчин бөгөөд унтраавал сайт зогсоно.

Нийтэд тогтвортой ажиллуулахын тулд Node.js 24 сервер эсвэл Docker ажиллуулах, **байнгын диск**, HTTPS хэрэгтэй. `DATA_DIR` дотор өгөгдлийн сан болон кино хадгалагдана. Түр зуурын диск бүхий hosting дээр тавибал өгөгдөл алдагдаж болно. Киноны багтаамж, үзэлтийн урсгалын зардал hosting-оос хамаарна; энэ төсөл үнэгүй видео хадгалалт өгөхгүй.

Жишээ Docker:

```bash
docker build -t lumi-cinema .
docker volume create lumi-data
docker run --rm -it -v lumi-data:/app/data lumi-cinema node scripts/create-admin.mjs
docker run -d --name lumi -p 127.0.0.1:8080:8080 \
  -v lumi-data:/app/data \
  -e PUBLIC_ORIGIN=https://YOUR-DOMAIN \
  -e COOKIE_SECURE=true \
  lumi-cinema
```

YOUR-DOMAIN-ийг өөрийн домэйноор солино. HTTPS reverse proxy-г 8080 руу холбож, том видео upload-ийн хэмжээ/хугацааны хязгаарыг тохируулна. Нийтэд гаргахын өмнө бодит MP4 файлаа iPhone, Android дээр тоглуулж шалгана.

## Хадгалалт ба backup

- `.env` — хувийн тохиргоо; GitHub-д оруулахгүй.
- `data/lumi.sqlite` — хэрэглэгч, төлбөр, киноны өгөгдөл.
- `data/media/` — кино, постер; GitHub-д оруулахгүй.
- `.gitignore` эдгээрийг хассан.
- Backup хийхдээ серверээ түр зогсоож **data хавтсыг бүхэлд нь** аюулгүй газарт хуулна. SQLite-ийн WAL/SHM файл байвал хамт хуулна. Restore хийхдээ мөн сервер зогссон байх ёстой.
- Хуучин файлыг сольсон ч дискнээс автоматаар устгахгүй; санамсаргүй устгалгүй байлгахын тулд цэвэрлэгээг тусад нь хийнэ.

## Утсанд суулгах / дараагийн апп

HTTPS дээр iPhone Safari → Share → Add to Home Screen, Android Chrome → Install app / Add to Home screen. Энэ нь **суулгаж болох вэб апп (PWA)**. App Store/Google Play-д нийтлэгдсэн native апп биш. REST API болон интерфейс тусдаа тул дараа нь native client эсвэл Capacitor wrapper нэмэх боломжтой. Кино offline татахгүй, интернэтээр үзнэ.

## Тест

```bash
npm test
```

Тест нь түр тусдаа өгөгдөл үүсгэж, бүртгэл → кино upload → хүсэлт → админ батлах → хамгаалалттай үзэх урсгал, зөвшөөрөлгүй хэрэглэгч, давхардсан хүсэлт, татгалзалт, үнэ өөрчлөх оролдлого, CSRF болон видео range-ийг шалгана. Тестийн видео нь зөвхөн byte-range fixture; кодек тоглуулахыг бодит кинотой тусад нь шалгана.

## Одоогийн хүрээ

Энэ хувилбар нэг кино = нэг бүтэн видео зарна. Олон ангит киноны анги бүрийн жагсаалт, VIP багц, QPay/MonPay, email/SMS нууц үг сэргээх, DRM, адаптив HLS, push мэдэгдэл ороогүй. Нэвтрэх нэрийг хадгалж, нууц үгээ мартахгүй байх шаардлагатай. Админ үүсгэхийг зөвхөн серверт хандах хүн CLI-аар хийнэ.

Видео үзэх эрхийг сервер шалгадаг ч эрхтэй хэрэглэгчийн дэлгэц бичих, видео хадгалах бүх аргыг техникийн хувьд хаах DRM байхгүй. «Download» товчийг нуусан нь DRM гэсэн үг биш.

Зөвшөөрөлтэй контентоо нийтлээрэй. Нийтэд нээхдээ өөрийн холбоо барих, үйлчилгээ, буцаалт болон нууцлалын бодлогыг бодит ажиллагаандаа тохируулан нэмнэ.
